### 🚀 Featured project — [Flybirds](https://github.com/AbanoubRashad/flybirds)
A production-grade DTC e-commerce platform:
- **Next.js 15 App Router** + Server Actions, strict TypeScript end to end
- **Prisma + PostgreSQL** relational catalog with variant-level stock
- **Optimistic cart** (Zustand) reconciled against live stock via TanStack Query
- **URL-driven faceted search** — every filtered page is shareable
- **Auth.js RBAC** (USER / ADMIN) enforced at the edge and on the server
- Stripe checkout + webhooks and an admin analytics dashboard in progress
